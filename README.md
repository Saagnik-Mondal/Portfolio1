# Saagnik Mondal - Personal Portfolio

Welcome to the source code of my personal portfolio website! 

This is a modern, interactive, and highly visual website designed to showcase my journey as a developer, my AI/ML projects, and my professional experience. I built this site with a focus on smooth animations, beautiful typography, and engaging 3D elements—giving visitors a premium, "cinematic" experience right in their browser.

## 🌟 Features

- **Cinematic Light Design:** A clean, paper-like palette with vibrant accents and film-grain overlays.
- **Interactive 3D Graphics:** Features a reactive 3D blob in the hero section that responds to scrolling and cursor movements.
- **Smooth Scrolling:** Silky smooth scrolling experience across the entire site.
- **Engaging Animations:** Dynamic text reveals, scrolling marquees, and kinetic transitions.
- **Responsive Layout:** Looks great and functions perfectly on desktops, tablets, and mobile phones.

## 🛠️ Built With

This project is built using modern web technologies:

- **[React](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)** - For building a robust component-based UI.
- **[Tailwind CSS](https://tailwindcss.com/)** - For rapid, utility-first styling and responsive design.
- **[Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)** - For rendering the interactive 3D graphics in the background.
- **[Framer Motion](https://www.framer.com/motion/)** - For the complex UI animations and transitions.
- **[Lenis](https://lenis.studiofreight.com/)** - For the smooth scrolling engine.
- **[Vite](https://vitejs.dev/)** - For lightning-fast local development and building.

## 🚀 How to Run Locally

If you want to download this code and run it on your own computer, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saagnik-Mondal/Portfolio1.git
   cd Portfolio1
   ```

2. **Install the dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the site:**
   Open your browser and navigate to `http://localhost:5173` (or whatever port Vite gives you in the terminal).
